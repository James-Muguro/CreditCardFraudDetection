# Original Data Science Approach

The original notebook and script this project started from — a data science workflow focused on model performance: preprocessing, feature scaling, training Random Forest/XGBoost classifiers, and evaluating with accuracy, precision, and recall.

The project has since been reworked into a data engineering pipeline (ingestion, validation, transformation, orchestrated storage, containerization, CI) — see the root [README](../README.md) for the current architecture. These files are kept as a reference point for that starting approach, not as active code.
